# Uttarakhand Gateways (UKG)

Uttarakhand's premier 0% brokerage real estate portal to buy, sell, and rent verified residential plots, luxury flats, cottages, and villas across Uttarakhand.

## Tech Stack
- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Motion
- **Backend**: Node.js, Express, MySQL / PostgreSQL adapter
- **Build Tool**: Vite

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Run Production Server
```bash
node server.js
```
or
```bash
node dist/server.cjs
```
