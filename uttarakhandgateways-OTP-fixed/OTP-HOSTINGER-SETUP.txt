UKG OTP / HOSTINGER SETUP

1. In Hostinger, create/use the mailbox:
   ukg@uttarakhandgateways.com

2. Add these environment variables to the Node.js application in Hostinger:
   EMAIL_USER=ukg@uttarakhandgateways.com
   EMAIL_PASSWORD=YOUR_HOSTINGER_EMAIL_PASSWORD
   SMTP_HOST=smtp.hostinger.com
   SMTP_PORT=465
   SMTP_SECURE=true

3. Do NOT commit your real EMAIL_PASSWORD to GitHub.

4. The application sends registration OTPs through Hostinger SMTP at:
   POST /api/send-otp

5. The frontend waits for the server response. If Hostinger email is not configured,
   the registration screen now shows an error instead of pretending the OTP was sent.

6. This project still keeps the OTP verification state in browser sessionStorage,
   matching the existing authentication architecture. For a production-grade auth
   system, move user accounts and OTP verification to a server/database later.

BUILD:
   npm install
   npm run build
   npm start
